# 排错

先确认三件事：**前缀在不在**、**用的是不是 VKD3D-Proton**、**显存守卫在不在跑**。

```bash
# 前缀（appid 就是 compatdata 目录名，通常是 2885173776）
PREFIX=~/.local/share/Steam/steamapps/compatdata/2885173776/pfx
ls "$PREFIX/drive_c/Program Files/yysls/Win32/deploy/launcher.exe"

# 显存守卫
systemctl --user status vram-guard
tail -n 40 ~/.local/state/yysls-steamos/vram-guard.log

# 游戏进程用的是哪个 vkd3d（先找到 yysls.exe 的 pid）
pid=$(pgrep -f yysls.exe | head -1); grep -iE 'd3d12core|libvkd3d' /proc/$pid/maps | sort -u
```

## 常见现象

| 现象 | 原因 / 处理 |
|---|---|
| 库里没有「燕云十六声（国服）」 | 重启一次 Steam；或手动「添加非 Steam 游戏」选安装包 `yysls_1.9.36_netease_setup.exe`，属性→兼容性→强制 GE-Proton |
| 点开始没反应 / 报错 | 属性→兼容性→强制使用 **GE-Proton10-32**（或 Proton Experimental） |
| 点开始又跑一遍安装器 | 快捷方式目标还是安装器。跑 `~/.local/share/yysls-steamos/post-install.sh` |
| 启动器界面小得离谱 | DPI 没写进去。重跑 `./install.sh`（会自动读 `Xft.dpi`），或 `./install.sh --dpi 288` |
| 启动器界面大得离谱 | DPI 写大了。`./install.sh --dpi 96` |
| 进游戏 ~20s 就闪退回到启动器 | 没用 VKD3D-Proton。检查 `yysls-launcher.service` 的 `WINEDLLPATH` / `WINEDLLOVERRIDES`，以及是不是用了裸 `wine` 启动 |
| 显存疯涨 / 桌面卡死 | 软件渲染没生效。确认注册表 `HKCU\Environment` 的 `QT_OPENGL=software`；`systemctl --user status vram-guard` 是否在跑 |
| 桌面被冻死只能硬重启 | 事故已发生。重启后**第一件事**就是确认 `vram-guard` enabled：`systemctl --user enable --now vram-guard` |
| 下载很慢 | 确认没走终端代理（Steam 会话无代理）；网易 CDN 实测可达 ~46MB/s |
| 提示反作弊错误 | 风险项。若网易加入内核级反作弊，Proton 会失效，无法绕过 |
| 手柄不生效 | 启动器界面不支持手柄，用鼠标/触屏；游戏内手柄正常。用燕窝则有输入桥 |

## 关键日志/文件位置

以 appid `2885173776` 为例：

| 东西 | 路径 |
|---|---|
| 启动器日志 | `<prefix>/drive_c/Program Files/yysls/Win32/deploy/launcher.log` |
| 引擎 assert 文本 | `…/yysls_fast/LocalData/check_hex.txt` |
| 账号/初始化流程 | `…/yysls_fast/LocalData/game_account.log`（内容按字节 -1 混淆） |
| 崩溃转储 | `…/users/steamuser/AppData/Local/UniSDK/CrashDump/<ver>/h72/`（标准 MDMP，异常流 type=6） |
| patch 日志 | `…/yysls_fast/LocalData/patch_log/patch_log_*.txt` |

判读：`launcher.log` 里 `enter game` → `detect window` 后**不再出现 `exit game`** = 游戏真的起来了。

## 手动修注册表

需要 GE-Proton 的 wine。以 GE-Proton10-32 为例：

```bash
G=~/.local/share/Steam/compatibilitytools.d/GE-Proton10-32
P=~/.local/share/Steam/steamapps/compatdata/2885173776/pfx

# 软件渲染（救命）
WINEPREFIX="$P" LD_LIBRARY_PATH="$G/files/lib/x86_64-linux-gnu:$G/files/lib" \
  "$G/files/bin/wine" reg add 'HKCU\Environment' /v QT_OPENGL /t REG_SZ /d software /f
WINEPREFIX="$P" LD_LIBRARY_PATH="$G/files/lib/x86_64-linux-gnu:$G/files/lib" \
  "$G/files/bin/wine" reg add 'HKCU\Environment' /v QT_QUICK_BACKEND /t REG_SZ /d software /f

# DPI
WINEPREFIX="$P" LD_LIBRARY_PATH="$G/files/lib/x86_64-linux-gnu:$G/files/lib" \
  "$G/files/bin/wine" reg add 'HKCU\Control Panel\Desktop' /v LogPixels /t REG_DWORD /d 288 /f
WINEPREFIX="$P" LD_LIBRARY_PATH="$G/files/lib/x86_64-linux-gnu:$G/files/lib" \
  "$G/files/bin/wine" reg add 'HKCU\Software\Wine\Fonts' /v LogPixels /t REG_DWORD /d 288 /f
```

## 改 Steam 快捷方式必须停 Steam

`shortcuts.vdf` 在 Steam 退出时会被覆盖。`post-install.sh` / `steam-shortcut.py` 已内置检查；
手动改时先：

```bash
systemctl --user stop steam-launcher        # 或 app-steam@autostart.service
# …改…
systemctl --user start steam-launcher
```

**务必保留 appid**（`steam-shortcut.py repoint` 已保证）。改 `AppName`/`Exe` 会重新计算 appid
→ compatdata 目录名变化 → Steam 认为游戏没了 → 重下 100G+。
