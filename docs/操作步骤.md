# 燕云十六声（国服·PC端）在 SteamOS 上运行 —— 操作步骤

> 本机：SteamOS 3.8.16 / Ryzen 5 5600X / RX 9070 XT 16G / 30G 内存
> 游戏：网易国服 PC 客户端（无 Linux 版、无 Steam 版），通过 Proton 运行。
> 国际服（Steam appid 3564740）是另一套账号/服务器，和国服不互通。

  `~/Games/yysls/yysls_1.9.36_netease_setup.exe`（248 MB，官方 h72.gdl.netease.com 直链）

  （appid `2885173776`，指向上面的安装包，已强制 `GE-Proton10-32`）
- ✅ 安装后自动改启动目标脚本：`~/Games/yysls/post-install.sh`
- ✅ 工具脚本：`~/Games/yysls/steam-shortcut.py`

## 你需要做的（大约 4 步）

### 第 1 步：切到桌面模式，点开安装
1. Steam 键 → 电源 → **切换到桌面模式**（安装器 GUI 需要鼠标/键盘，游戏模式下不好操作）。
2. 打开 Steam（桌面模式下的那个），库 → 找到 **「燕云十六声（国服）」** → 点「开始」。
3. 会弹出网易安装器窗口（第一次会先初始化 Proton 前缀，可能要等一会）。

### 第 2 步：在安装器里选版本
- 资源包选 **极速版（约 60GB）** 或 **标准版（约 100GB）**。
  本机是 9070 XT，两个都跑得动；极速版下载快、帧率更高，先玩推荐极速版。
- **安装路径不要改**（保持默认 `C:\Program Files\yysls`，实际落在 Proton 前缀里）。
- 等待下载完成（约 60GB；网易 CDN 实测 ~46MB/s，20~40 分钟）。
- 装完后**不要点"进入游戏"**，直接关掉安装器窗口。

### 第 3 步：把启动目标改成真正的启动器
在桌面模式的终端里运行：

```bash
~/Games/yysls/post-install.sh
```

这个脚本会：找到 `launcher.exe` → 停 Steam → 改写快捷方式目标 → 重启 Steam。
（不跑它的话，每次点开都会先执行一遍安装器。）

### 第 4 步：开始游戏
1. 回到游戏模式（或桌面模式都行），库 → 点 **「燕云十六声（国服）」**。
2. 出现启动器，点「进入游戏」。
3. 如果黑屏：按 **Steam 键** 打开左侧菜单 → 选 **「登录」** → 按 **B** 返回，就能看到登录界面。
4. 输入网易账号（国服是网易通行证，和国际服账号不通用）。

## 排错

| 现象 | 处理 |
|---|---|
| 库里没有「燕云十六声（国服）」 | 重启一次 Steam；或手动「添加非 Steam 游戏」选 `~/Games/yysls/yysls_1.9.36_netease_setup.exe`，属性→兼容性→强制 Proton |
| 点开始没反应 / 报错 | 属性 → 兼容性 → 强制使用 **Proton Experimental** 或 **GE-Proton10-32** |
| 启动器不显示 / 黑屏 | 按 Steam 键开菜单再返回；或在桌面模式先跑一次 |
| 手柄不生效 | 启动器界面不支持手柄，用鼠标/触屏；进游戏后手柄正常 |
| 下载很慢 | 确认没走代理（`.bashrc` 里的 `proxy-on` 只影响终端，Steam 会话没代理） |
| 提示反作弊错误 | 见下方"风险" |

## 风险 / 注意

- **反作弊是唯一变数**：目前社区实测（含 SteamOS 原生教程、ProtonDB 国际服白金）能跑，
  说明是用户态反作弊。若网易某次更新加入内核级反作弊（自家驱动 / ACE 类），Proton 会失效。
- 国服与国际服**账号、服务器、进度全部独立**。
- 游戏装在 Proton 前缀里：`~/.local/share/Steam/steamapps/compatdata/2885173776/`。
  卸载/清理时注意这目录会占 60~100GB。
- 首次进游戏前建议确认显示分辨率：本机 HDMI 支持 4K，但 gamescope 默认参数偏掌机，
  可在游戏模式「设置→显示」里调。
